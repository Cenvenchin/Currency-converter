# Currency Converter

Простой и безопасный скрипт на Python для получения актуальных курсов доллара (USD) и евро (EUR) по отношению к российскому рублю (RUB). 

Программа работает без API-ключей и регистраций, комбинируя два открытых источника:
* **Frankfurter API** — для получения базового отношения EUR к USD.
* **ExchangeRate-API** — для получения стоимости USD в рублях.

Курс евро к рублю рассчитывается автоматически с использованием кросс-курса.

## Особенности
* Полностью бесплатное использование без авторизации.
* Встроенная защита от сетевых зависаний (таймауты HTTP-запросов).
* Безопасная обработка ошибок при падении сети или получении некорректных данных (не JSON).

## Требования
* Python 3.7 или выше
* Библиотека `requests`
